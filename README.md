# CZL 图床 Android 客户端

[CZL 图床 (img.czl.net)](https://img.czl.net) 的 Android App：浏览图库、上传照片、管理相册与分享链接。

本仓库只用于编译和发布安装包。

## 下载与安装

- 下载页：https://connect.czl.net/download/czlimg ，或本仓库 [Releases](../../releases/latest)
- 下载 `czlimg-android-<版本>.apk` 后打开安装；首次安装需在系统提示中允许「安装未知应用」
- 支持 Android 7.0 及以上 (arm64 / armv7)
- 每个 Release 附带 `SHA256SUMS`，可用于校验下载文件

## 更新

App 启动时会检查新版本，确认后在 App 内下载并校验安装包，再交给系统安装；也可在「我的 › 检查更新」手动检查。
